# Refatoração de Código

Este repositório contém um exercício prático de refatoração de código em Python, realizado na aula de Arquitetura de Software do dia 09 de setembro.

O código foi refatorado para aplicar boas práticas e princípios SOLID (como o *Single Responsibility Principle* e o *Open/Closed Principle*), utilizando Injeção de Dependências para separar as responsabilidades de Validação, Cálculo de Desconto, Persistência e Notificação.
